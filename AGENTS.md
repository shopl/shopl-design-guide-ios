# SDG Builder repository guidance

Read and apply [.agents/skills/ios-sdg-minimum-rules/SKILL.md](.agents/skills/ios-sdg-minimum-rules/SKILL.md) when editing SDG components and sample screens. Repository guidance does not expand the permitted source paths. Preserve public API compatibility, existing user changes and resource-owner boundaries.

For every new or modified SDG component or template, add or update documentation comments and explicitly declare its component design version as defined in the Skill. Verify the exact version from design requirements; do not invent or automatically increment it. Keep sample version displays consistent with the component.
